Texo - MCP

The memory of Texo as a remote MCP server, behind the Texo token.

  • POST /texo/mcp: one JSON-RPC message per request, with the person's token as bearer; the tools run as the person.
  • The instructions of the server are the rules of the session; the tools are those of the routes, with the same answers and checks.
  • A write waits for confirm: true, after the person's yes.
