Texo - Vector

Vectors for the memory of Texo: a search by meaning over the episodes, the facts and the lessons, fused with the lexical search, and the near-duplicate lessons found by meaning. Optional: without it the hub is lexical, as before.

  • One table of vectors (pgvector, HNSW index) kept by a cron: the vectors missing, of a changed text or of another model are computed, those of records out of the scope are dropped. Never the rules.
  • The search takes mode: lexical, semantic or hybrid (reciprocal rank fusion, the default); every hit says which search found it.
  • The embeddings come from a local service (Text Embeddings Inference, POST /embed) named in the system parameters; an endpoint outside the local network is refused unless the administrator opts in: no text of the memory leaves the machine by default.
  • Without the extension vector on the database the module installs, warns, and the search stays lexical.
