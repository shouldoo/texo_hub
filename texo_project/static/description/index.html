Texo - Project

Project routes for agents, behind the Texo token: the questions an agent asks most when it works on a client task, answered in a compact format meant for an LLM.

  • project/my_work: open project tasks assigned to the user.
  • project/task: task summary, plain-text description, subtasks, milestone and latest chatter messages.
  • project/task_note: internal note posted as the user, escaped plain text.
  • project/project: the project as the agent reads it: its description, its milestones as the roadmap and its last update as its present, with a warning when the present is missing or old.
  • project/update: a project update written as the user, the new present of the project.

Everything runs as the user: a task or project the user cannot read answers like one that does not exist.
