Texo

Makes Odoo the identity provider of Texo: people, hub roles and personal hub tokens live in Odoo, and every agent route of the hub modules runs as the person behind the token.

  • API key scope Texo in the standard New API Key wizard: such a key opens only the hub routes, never /json/2 or XML-RPC.
  • Hub tokens always expire, within texo.token_max_days days (default 90).
  • Hub roles Member, Lead and Administrator as Odoo groups.
  • POST /texo/v1/whoami: identity and hub role behind a token, for the agent's client.
  • Users > Texo Tokens: every hub token with its owner, expiry and last use.
  • Generic read-only routes for agents (search_read, read_group, fields, models): the agent writes the query, Odoo runs it as the user on a read-only cursor, without technical models or sensitive fields.
