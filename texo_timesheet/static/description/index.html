Texo - Timesheet

Hours on a task from an agent, as the person who gives them, behind the Texo token.

  • POST /texo/v1/project/log_time: one timesheet line on a task the user can read, on the user's employee record, with the worklog line as description.
  • The task context gains the last worklog lines and the hours spent and allocated.
  • Installed automatically with texo_project and hr_timesheet.
